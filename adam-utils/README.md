# adam-utils

The parts of [bdg-utils](https://github.com/bigdatagenomics/utils) 1.0.1 that ADAM uses
(`cli`, `interval.array`, `io` and the `misc.SparkFunSuite` test helper), copied here and
ported to Scala 2.13 and Spark 4. bdg-utils was never published for Scala 2.13.

Package names are unchanged (`org.bdgenomics.utils.*`), so existing imports keep working.
